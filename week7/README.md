# Week 7 – Next-Token Probability Analysis

## 1. Aim

To inspect the logits and top-k next-token candidates generated by a small open-source language model using Hugging Face Transformers and PyTorch.

## 2. Technologies Used

- Python 3.14
- PyTorch
- Hugging Face Transformers
- DistilGPT-2
- Accelerate
- VS Code

## 3. Project Files

The Week 7 folder contains the following files:

```text
week7/
│
├── main.py
├── test_model.py
├── requirements.txt
├── README.md
│
└── outputs/
    └── next_token_results.txt
```

### File Description

- `main.py` – Contains the Python program to calculate logits, convert them into probabilities, identify the top-5 next-token candidates, and save the results.
- `test_model.py` – Checks whether the tokenizer and DistilGPT-2 model are loaded successfully.
- `requirements.txt` – Contains the Python libraries required for the experiment.
- `outputs/next_token_results.txt` – Stores the generated next-token candidates, logits, and probabilities.
- `README.md` – Provides the experiment description, execution steps, and results.

## 6. Experiment Details

The input prompt used for the experiment was:

`Artificial intelligence is`

The tokenizer converted the input prompt into four token IDs:

`[8001, 9542, 4430, 318]`

The model generated logits with the shape `(1, 4, 50257)`.

The logits from the final input position were extracted and converted into probabilities using the Softmax function. The `torch.topk()` function was then used to identify the five candidates with the highest probabilities.

## 7. Observed Results

The top-5 next-token candidates generated by DistilGPT-2 were:

| Rank | Token | Probability |
|---|---|---:|
| 1 | a | 16.4362% |
| 2 | the | 6.6132% |
| 3 | not | 4.8673% |
| 4 | one | 3.6778% |
| 5 | an | 3.5226% |

The most probable next token was **"a"**, with a probability of 16.4362%.
