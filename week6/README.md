### Step 6: Create the Golden Question Set

I created `golden_set.json` containing 30 questions related to different Generative AI topics.

The questions cover:

- Tokenization
- BPE, WordPiece, and SentencePiece
- Token Economics
- Context Window and Rate Limits
- Autoregressive Generation
- Next Token Prediction
- Greedy Decoding and Sampling
- Temperature, Top-K, and Top-P


The output was `30`, confirming that the golden question set contained 30 questions.

### Step 7: Create main.py

I created the `main.py` file to perform the baseline evaluation.

The program performs the following operations:

1. Reads the questions from `golden_set.json`.
2. Sends each question to the Llama 3.2 model through the Ollama API.
3. Receives the generated answer.
4. Compares the generated answer with the expected keywords.
5. Calculates the keyword coverage score.
6. Assigns PASS or REVIEW status based on the score.
7. Stores the evaluation results in a CSV file.

### Step 10: Evaluate the Generated Answers

The program compares the generated answers with the expected keywords.

The keyword coverage score is calculated using the following formula:

```text
Keyword Coverage Score =
(Matched Keywords / Total Expected Keywords) * 100
```

The status is assigned based on the following conditions:

| Score | Status |
|---|---|
| Greater than or equal to 60% | PASS |
| Below 60% | REVIEW |

This evaluation measures keyword coverage. It does not independently confirm the factual correctness or complete meaning of the generated answers.

### Step 11: Generate the Evaluation Results

After processing the questions, the program saved the evaluation details in:

```text
baseline_results.csv
```

The CSV file contains the question ID, expected answer, generated answer, matched keywords, missing keywords, score, status, source, model name, and release information.
